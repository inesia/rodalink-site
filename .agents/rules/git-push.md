# Git Push Behavior Rule

JANGAN PERNAH menjalankan `git push` kecuali USER secara eksplisit meminta push dalam prompt/permintaan saat ini (misalnya "push ke git", "push repo", "git push").

Jika user tidak meminta push secara tertulis, HANYA lakukan edit file dan commit lokal jika diperlukan, tetapi JANGAN jalankan `git push`.
